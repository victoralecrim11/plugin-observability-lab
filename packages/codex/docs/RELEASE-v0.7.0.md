# Observability Dev Toolkit v0.7.0

Adiciona importar-template (Zabbix YAML/JSON/XML) e importar-dashboard (Grafana JSON).
Os workflows orientam importação real usando navegador, Computer Use ou API
quando disponíveis e permitidos, com validação, resolução de conflitos, backup,
autorização específica e verificação após importar. Sem ferramentas ou acesso,
relatam bloqueio; não simulam execução.

Claude: 21 comandos. Codex: 21 operações e uma entrada contextual (22 entradas,
sem Source Command). Antigravity: uma skill contextual com os mesmos 21 workflows.

O catálogo canônico agora centraliza os nomes esperados nas validações. Nenhum
sistema Zabbix/Grafana foi modificado durante o desenvolvimento desta release.
